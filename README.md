# 🛍️ ShopEase — React E-Commerce Platform

A responsive e-commerce web application built with React, featuring product browsing, category filtering, cart management, and a checkout flow.

🔗 **Live Demo:** [shopease.vercel.app](#) *(replace with your deployed link)*

## ✨ Features

- 🛒 Product listing with category filters and search
- 📄 Product detail pages with dynamic routing (React Router)
- ➕ Add to cart / remove from cart with quantity updates
- 💾 Cart persistence using localStorage
- 💳 Simple checkout flow with order summary
- 🌙 Dark mode toggle
- 📱 Fully responsive design (mobile-first)

## 🛠️ Tech Stack

- **Frontend:** React, React Router
- **State Management:** Context API
- **Styling:** Tailwind CSS / Bootstrap
- **Deployment:** Vercel / Netlify

## 🚀 Getting Started

\`\`\`bash
git clone https://github.com/GVishnu17/shopease.git
cd shopease
npm install
npm start
